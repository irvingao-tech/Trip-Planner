# Starter Repository Skeleton

This folder is intentionally minimal.

Recommended bootstrap:
1. Create a fresh Next.js app.
2. Copy `/docs` and `/AGENTS.md` to repository root.
3. Merge the starter files instead of blindly overwriting framework-generated config.
4. Install dependencies.
5. Start with Demo Mode.
6. Ask Codex to implement Phase 0 and Phase 1 only.

Important: versions in this starter use `latest` placeholders by design. Pin versions after initial installation and commit the lockfile.
